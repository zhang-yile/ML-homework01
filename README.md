# 机器学习第一次作业

## 一、奇异值分解

### 1. 什么是奇异值分解

奇异值分解简称 SVD。它可以把一个矩阵分解成三个矩阵相乘的形式：

```math
A=U\Sigma V^T
```

其中，$U$ 和 $V$ 是正交矩阵，也就是它们的列向量长度都是 1，并且两两垂直。$\Sigma$ 的对角线上是非负数，称为奇异值，一般从大到小排列。

我的理解是：一个比较复杂的矩阵变换，可以拆成几个更容易理解的变换。奇异值的大小反映了不同方向上的缩放程度。

### 2. 分解的主要步骤

设 $A$ 是一个 $m\times n$ 的实矩阵，分解步骤如下：

1. 计算 $A^TA$。
2. 求出 $A^TA$ 的特征值和对应的单位特征向量，把特征值从大到小排列，对应的特征向量组成矩阵 $V$。这些向量需要相互正交。
3. 对特征值开平方，得到奇异值，即 $\sigma_i=\sqrt{\lambda_i}$，再按原矩阵的大小组成 $\Sigma$。
4. 对非零奇异值，用 $u_i=Av_i/\sigma_i$ 求出 $U$ 中的向量。如果向量数量不够，再补充与已有向量正交的单位向量。
5. 计算 $U\Sigma V^T$，检查是否等于原矩阵。

这里对特征值开平方是有依据的。因为

```math
A^TA=V\Sigma^T\Sigma V^T,
```

所以 $A^TA$ 的特征值就是奇异值的平方。另外，$A^TA$ 的特征值不会小于零，因为

```math
x^TA^TAx=\|Ax\|^2\geq0.
```

需要注意，奇异值为零时，不能使用除以 $\sigma_i$ 的公式。

### 3. 自己设计的例子

选择一个比较方便计算的矩阵：

```math
A=\begin{bmatrix}3&0\\4&0\end{bmatrix}.
```

**第一步：计算 $A^TA$。**

```math
A^TA=
\begin{bmatrix}3&4\\0&0\end{bmatrix}
\begin{bmatrix}3&0\\4&0\end{bmatrix}
=
\begin{bmatrix}25&0\\0&0\end{bmatrix}.
```

**第二步：求特征值和特征向量。**

由特征方程

```math
\det(A^TA-\lambda I)=(25-\lambda)(-\lambda)=0
```

得到 $\lambda_1=25$，$\lambda_2=0$。对应的单位特征向量可以取为

```math
v_1=\begin{bmatrix}1\\0\end{bmatrix},\qquad
v_2=\begin{bmatrix}0\\1\end{bmatrix}.
```

因此

```math
V=\begin{bmatrix}1&0\\0&1\end{bmatrix}.
```

**第三步：求奇异值。**

```math
\sigma_1=\sqrt{25}=5,\qquad \sigma_2=0,
```

所以

```math
\Sigma=\begin{bmatrix}5&0\\0&0\end{bmatrix}.
```

**第四步：求 $U$。**

```math
u_1=\frac{Av_1}{5}=\begin{bmatrix}3/5\\4/5\end{bmatrix}.
```

由于第二个奇异值为零，不能继续用除法计算。可以选择与 $u_1$ 垂直、长度为 1 的向量：

```math
u_2=\begin{bmatrix}-4/5\\3/5\end{bmatrix}.
```

这两个向量的内积为 $-12/25+12/25=0$，长度也都为 1。因此

```math
U=\begin{bmatrix}3/5&-4/5\\4/5&3/5\end{bmatrix}.
```

**第五步：检查结果。**

```math
U\Sigma V^T=
\begin{bmatrix}3/5&-4/5\\4/5&3/5\end{bmatrix}
\begin{bmatrix}5&0\\0&0\end{bmatrix}
\begin{bmatrix}1&0\\0&1\end{bmatrix}
=
\begin{bmatrix}3&0\\4&0\end{bmatrix}=A.
```

因此，这个矩阵的奇异值分解完成了。

### 4. 对应用的理解

SVD 可以用于图片压缩和数据降维。如果一个矩阵有很多奇异值，可以只保留较大的几个，得到原矩阵的近似结果。这样会损失一部分信息，但也可以减少需要保存的数据。

## 二、贝叶斯过程及项目案例

### 1. 对贝叶斯过程的理解

我把贝叶斯过程理解为：先有一个初步判断，再根据新得到的数据修改判断。

贝叶斯公式为

```math
P(A\mid B)=\frac{P(B\mid A)P(A)}{P(B)}.
```

其中，$P(A)$ 是看到新证据之前的概率，称为先验概率；$P(A\mid B)$ 是看到证据 $B$ 之后更新的概率，称为后验概率。

例如，检测系统提示一个产品有缺陷，不代表它一定有缺陷。还需要考虑原本有多少产品存在缺陷，以及检测系统会不会误报。

### 2. 项目问题

这里设计一个“产品缺陷检测”的小项目。项目需要根据检测结果，判断一个产品真正存在缺陷的可能性。以下数据是为了说明计算过程而设置的模拟数据。

假设：

- 一批产品中，有缺陷的产品占 $5\%$。
- 对于真正有缺陷的产品，系统有 $90\%$ 的概率检测出异常。
- 对于正常产品，系统有 $10\%$ 的概率错误地提示异常。

现在的问题是：如果系统提示某件产品异常，那么它真正有缺陷的概率是多少？

### 3. 建立数学模型

设事件 $D$ 表示“产品有缺陷”，$\bar D$ 表示“产品正常”，事件 $T$ 表示“系统提示异常”。

根据题目条件：

```math
P(D)=0.05,\qquad P(\bar D)=0.95,
```

```math
P(T\mid D)=0.90,\qquad P(T\mid\bar D)=0.10.
```

我们的目标是求 $P(D\mid T)$。

这里假设这些比例适用于当前这批产品，且产品只有“有缺陷”和“正常”两种情况。

### 4. 计算过程

系统提示异常有两种来源：一是真正有缺陷并被检出，二是正常产品被误报。根据全概率公式：

```math
\begin{aligned}
P(T)
&=P(T\mid D)P(D)+P(T\mid\bar D)P(\bar D)\\
&=0.90\times0.05+0.10\times0.95\\
&=0.045+0.095\\
&=0.14.
\end{aligned}
```

再代入贝叶斯公式：

```math
\begin{aligned}
P(D\mid T)
&=\frac{P(T\mid D)P(D)}{P(T)}\\
&=\frac{0.90\times0.05}{0.14}\\
&\approx0.3214.
\end{aligned}
```

所以，系统提示异常后，产品真正有缺陷的概率约为 **32.14%**。

为了更直观地理解，可以假设有 1000 件产品，按这些比例计算预期数量：

| 产品情况 | 预期数量 | 预计被提示异常的数量 |
|---|---:|---:|
| 有缺陷 | 50 | 45 |
| 正常 | 950 | 95 |
| 合计 | 1000 | 140 |

在预计被提示异常的 140 件产品中，有缺陷的为 45 件，因此比例为 $45/140\approx32.14\%$，与公式结果一致。实际抽检数量会有随机波动。

### 5. 新证据如何继续更新判断

假设对该产品再用另一种方法复检。这种方法对缺陷产品的检出率为 $80\%$，对正常产品的误报率为 $5\%$。设 $R$ 表示复检也提示异常。

为了方便建立模型，假设在给定产品真实状态后，两次检测结果相互独立。只有在这个假设成立时，才能直接使用下面的计算。

将第一次检测后的概率作为新的先验：

```math
\begin{aligned}
P(D\mid T,R)
&=\frac{0.80\times P(D\mid T)}
{0.80\times P(D\mid T)+0.05\times[1-P(D\mid T)]}\\
&=\frac{0.80\times(9/28)}{0.80\times(9/28)+0.05\times(19/28)}\\
&\approx0.8834.
\end{aligned}
```

两次检测都提示异常后，产品有缺陷的概率约为 **88.34%**。这体现了贝叶斯过程：获得新的证据后，再更新原来的判断。

如果只是同一台设备对同一张图片重复判断，两次结果可能高度相关，不能直接当作独立的新证据。

### 6. 在项目中的作用

这个模型可以帮助项目安排人工复检。第一次提示异常时，可以先复查，再结合复检结果决定如何处理。

这个例子也说明，$P(T\mid D)$ 和 $P(D\mid T)$ 不是同一个概率。虽然系统能检出 $90\%$ 的缺陷产品，但不代表它提示异常的产品中有 $90\%$ 都存在缺陷。原本的缺陷比例和误报率也会影响最终结果。

## 三、交叉熵的定义、原理及应用

### 1. 交叉熵的定义

交叉熵常用来评价模型给出的概率预测。设真实分布为 $p$，模型预测分布为 $q$，则

```math
H(p,q)=-\sum_i p_i\ln q_i.
```

这里使用自然对数。可以简单理解为：模型给真实结果分配的概率越低，受到的惩罚越大。

如果真实类别的概率在预测中被设为零，损失就会趋于无穷大。真实概率为零的项按零处理。

### 2. 为什么可以用它作为损失函数

对于一个二分类问题，设真实标签 $y$ 为 0 或 1，模型预测为正类的概率为 $q$，则真实标签出现的概率为

```math
P(y\mid q)=q^y(1-q)^{1-y}.
```

我们希望模型给真实标签的概率越大越好。对它取负对数，得到

```math
\begin{aligned}
L
&=-\ln[q^y(1-q)^{1-y}]\\
&=-[y\ln q+(1-y)\ln(1-q)].
\end{aligned}
```

这就是二分类交叉熵。取负对数后，最大化真实标签的概率就变成了最小化损失。

- 当 $y=1$ 时，$L=-\ln q$。
- 当 $y=0$ 时，$L=-\ln(1-q)$。

例如真实标签为 1，预测概率是 $0.9$ 时，损失为 $-\ln0.9\approx0.1053$；预测概率是 $0.1$ 时，损失为 $-\ln0.1\approx2.3026$。可以看到，对真实类别给出很低的概率，会产生更大的损失。

### 3. 用具体例子推导

假设有 10 个样本，其中 3 个是正类，7 个是负类。为了简化问题，假设模型对每个样本都预测相同的正类概率 $q$。

平均交叉熵为

```math
L(q)=-\frac{1}{10}[3\ln q+7\ln(1-q)]
=-0.3\ln q-0.7\ln(1-q).
```

为了求损失最小时的 $q$，对它求导：

```math
L'(q)=-\frac{0.3}{q}+\frac{0.7}{1-q}.
```

令 $L'(q)=0$，得到

```math
0.7q=0.3(1-q),
```

所以

```math
q=0.3.
```

再检查二阶导数：

```math
L''(q)=\frac{0.3}{q^2}+\frac{0.7}{(1-q)^2}>0,\qquad0<q<1.
```

因此，$q=0.3$ 时损失最小。代入几个数值进行比较：

| 预测的正类概率 | 平均交叉熵 |
|---|---:|
| $0.3$ | $0.6109$ |
| $0.5$ | $0.6931$ |
| $0.8$ | $1.1935$ |

在这个例子中，实际正类比例为 $0.3$，预测概率也为 $0.3$ 时，损失最小。这里的结论建立在“所有样本都输出相同概率”的条件下。

### 4. 交叉熵与信息熵的关系

信息熵表示一个分布本身的不确定程度：

```math
H(p)=-\sum_i p_i\ln p_i.
```

交叉熵与它的关系为

```math
H(p,q)=H(p)+D_{\mathrm{KL}}(p\|q),
```

其中

```math
D_{\mathrm{KL}}(p\|q)=\sum_i p_i\ln\frac{p_i}{q_i}\geq0.
```

把右边两项展开，就能得到交叉熵的定义。因此，真实分布固定时，预测分布与它一致，交叉熵就达到最小值。上面的例子中，最小损失不是零，而是真实分布的信息熵，约为 $0.6109$。

### 5. 实际应用

在产品缺陷检测中，可以把“有缺陷”设为 1，“正常”设为 0。模型输出缺陷概率，再通过交叉熵计算预测与标签之间的差别，训练时不断调整参数，让平均损失下降。

交叉熵也能用于多分类。例如识别猫、狗、鸟时，如果真实类别是猫，模型给猫的概率为 $0.7$，那么这个样本的损失就是

```math
L=-\ln0.7\approx0.3567.
```

通过这些例子，我理解到，交叉熵不只是看模型是否猜对，还会考虑模型给正确答案分配了多大的概率。
